# 暗含景别改法示例（五档对照）

剧本 △ 行不写景别名，但必须把机位写死。下面每组「改前 → 改后」，改后都只剩一个位置。
全部取自本仓库示例剧本《修车铺》的世界观，人物为虚构。

---

## 1. T1 全景 · 场首定场

**改前**
```
△ 老陈蹲在车边，手电咬在嘴里，光柱贴着地面扫过去，照亮了半只轮胎。
```
问题：有细节（手电咬在嘴里），但**这一格在哪儿**没说。观众不知道是铺子里还是马路上。

**改后**
```
△ 铺子里只吊着一盏灯，灯下是那辆半拆的车。老陈蹲在车边，手电咬在嘴里，
   光柱贴着地面扫过去，照亮了半只轮胎。
```
→ 空间 + 人 + 标志物（吊灯／车）。后面紧跟的本事不变，只是先给一个「哪儿」。

---

## 2. T2 中景 · 两人关系

**改前**
```
△ 老陈站起来，踢了踢轮胎。
```
问题：能拍，但机位仍悬空——可以全景跟，也可以只拍脚。

**改后**
```
△ 老陈站起来，跨过小王腿边那截水管的距离，抬脚踢了踢轮胎，两人之间隔着一只工具箱。
```
→ 距离一说清，机位就被逼到中间：中景，两人同框、工具箱在前景。

---

## 3. T3 近景 · 反应镜头

**改前**
```
△ 老陈点了点头。
```
问题：点头可以是全景里一个小动作，也可以是大特写。差别很大。

**改后**
```
△ 老陈点了点头，下巴压下去又抬起来，眼睛没离开小王的手，身后那面墙糊成一片灰。
```
→ 「眼睛没离开手」+「背景糊成一片」= 近景。没有出现「近景」二字。

---

## 4. T4 特写 · 情绪落点

**改前**
```
△ 老陈没接话。
```
问题：什么都没说，也没给画面。

**改后**
```
△ 只看得见他捏着那截胶条的那两根手指，指甲缝里嵌着黑泥，胶条被捏得变了形。
```
→ 「只看得见」+「两根手指」把框裁到只剩手。这场戏的情绪落点在这一格。

---

## 5. T0 大远景 · 尺度对撞

**改前**
```
△ 路灯下停着一辆黑色轿车，车门开着。
```
问题：信息够了，但没给比例，读起来像中景。

**改后**
```
△ 整条街空着，路灯只照亮脚下一小块，那辆黑色轿车停在光边外，车门开着，
   从这头看过去小得像一只箱子。
```
→ 人与环境比例悬殊，观众自动读成远景。注意这里**没有写「大远景」**。

---

## 反例：越界与跨档

| 写法 | 问题 |
|---|---|
| `△ 特写老陈的手。` | 🔴 写了景别名，越界到分镜层（机检 S1 直接 FAIL） |
| `△ 手指捏着胶条，指甲缝嵌着黑泥，整条街空得没人。` | 🟡 一格装不下：T4 的手指和 T0 的空街不能同框（S2 提醒）。拆两条，或用遮挡过渡 |
| `△ 镜头从轮胎推到老陈脸上。` | 🔴 元叙事，分镜的活 |

---

## 机检怎么看

```bash
python3 scripts/lint_shot_scale.py parsed.json -o 镜头体检.md --shotlist 分镜草表.md
```

- 报告里的**档位未判定**是词表口径，不是稿子缺陷——它说的是「机检没抓到尺度线索，得人看图」
- 草表按「同档视为镜头不切」输出，可直接当提示词的 framing 字段
- 目标不是把未判定降到 0，而是：**S1 = 0、S4 = 0、同款收束 ≤5%**
