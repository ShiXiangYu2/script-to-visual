# 改写规则：功能性动作 → 文学画面描述

> 提炼自 `vendor/show-emotion.md`（情绪外显库）、`vendor/expand_SKILL.md`（正文扩写）、
> `vendor/visual_universal-rules.md`（AI 视频通用规则 U3/U9/三细节检查）。
> 本文件是**模型改写时唯一要遵守的操作规则**。

---

## 一、总原则：把「告知」改成「可见」

剧本 △ 行的通病是**只交代事件、不交代画面**。
改写的唯一目标：让读者/AI 视频模型**看见**这一拍，而不是被告知这一拍发生了什么。

```
❌ △ 老陈走过去看了看车。              ← 事件清单，镜头无从下手
✅ △ 老陈绕着车走了半圈，蹲下来，手指在轮胎侧壁上按了两下，橡胶陷进去又弹回来，
     他直起身，用鞋尖点了点那道口子。   ← 连续可见动作 + 幅度 + 触碰反应
```

**判据**：改写后能否在脑子里画出一格分镜？能 → 合格；不能 → 重写。

---

## 二、四步操作法（每条 △ 行都走一遍）

| 步 | 动作 | 说明 |
|---|---|---|
| 1 **拆事实** | 圈出原文全部剧情事实（时间、人物、物件、动作结果、空间关系） | 这些是**不可改动的锚点**，一条都不能丢 |
| 2 **找主体** | 明确这一拍镜头跟着谁/什么 | 一条 △ 行只跟一个主体；多个主体就拆成多条，但不新增情节 |
| 3 **补可见** | 给主体补 1–2 个**物理细节**：微动作、姿态幅度、速度节奏、声音、光线/质感反应 | 从下面「五通道」里挑最准的 1–2 条，别全堆 |
| 4 **顺时序** | 按动作发生的真实先后连成一句，短句为主，句长交错 | 先发生的先写；不倒叙、不插叙、不加解释 |

---

## 三、五通道（补可见细节时从哪里取）

1. **身体微动作**：指节攥、肩一沉、脚跟碾地、手在半空顿住、膝盖撑起来
2. **幅度与节奏**：慢慢、顿了一下、一口气、连着两下、忽然停住、始终没动
3. **声音锚点**：哼了一声、桶底刮过地面、扳手碰铁皮、水顺着檐口滴下来
4. **物件/环境反应**（克制）：水泥地上的鞋印、门缝里渗出的水、光斜切进来照见浮尘
5. **视线落点**：目光从车头移到挡风玻璃、盯着一个点出神、别开眼

> 情绪一律走 `02-情绪外显对照表.md`：不写"他很担心"，写"他蹲下去，把排水口扒开"。

---

## 四、AI 可演的硬约束（来自 visual-skills U3/U9）

**可以写**：能被摄影机记录的一切 —— 身体动作、姿态、速度、方向、视线、触碰、物件位移、光影变化、声音。

**禁止写**：
- 纯心理：`感到 / 觉得 / 心想 / 意识到 / 心里一紧 / 松了口气 / 暗自`
- 抽象评价：`气氛凝固 / 意味深长 / 说不出的复杂 / 很专业 / 极有张力`
- 无法渲染的比喻：`心如刀绞 / 像被抽空了 / 时光仿佛停住`
- 元叙事：`镜头拉近 / 特写 / 配乐起`（这是分镜的事，不是剧本 △ 行的事）

**三细节检查**（visual-skills U12）：每条改写至少含 **1 个物理微动作** +（可选）**1 个环境压力** +（可选）**1 个声音/视觉锚点**。
短 △ 行（如"老陈站在车边看了一会儿"）给足 1 个微动作 + 1 个视线落点即可，不必强凑三条。

---

## 五、克制与文风（防止改过头）

| 要 | 不要 |
|---|---|
| 1–2 个准细节 | 一条堆五个动作、连着三个比喻 |
| 短句为主，长短交错 | 一长串形容词、排比句 |
| 具体名词（扳手、轮胎、卷帘门） | 空泛词（东西、情况、某种、氛围） |
| 成年人的动作是"收着的" | 嚎啕、剧烈颤抖、夸张肢体 |
| 动作完就停（留白） | 补一句解释"这说明他其实……" |
| 保留 `△ ` 前缀、常规标点 | 直角引号「」、✦✨装饰符、破折号连发 |

**长度参考**：原 △ 行 10–25 字 → 改写后 30–70 字为宜。超过 90 字通常是堆细节了，删。

---

## 六、几种典型 △ 行的改法

| 原文类型 | 改法 | 例 |
|---|---|---|
| **结果式**（"车修好了，油污也擦干净了"） | 补可见的**完成态痕迹** | `车身擦得发干，轮毂上还挂着一线水；地上的油污清走了，水泥地上留着几道没干透的深色印子。` |
| **动作清单**（"走过去，看了一眼，开始修"） | 拆成**连续动作 + 幅度 + 声音** | 见本文件开头示例 |
| **静态站立**（"站在车边看了一会儿"） | 给**姿态 + 视线路径 + 停顿** | `老陈抱着胳膊站在车边没动，目光从车头慢慢移到挡风玻璃，又落到墙根那道水痕上，停了几秒。` |
| **情绪隐含**（"没接话，蹲下去"） | 用**动作承接情绪**，不点破 | `老陈没接话，把扳手往地上一放，蹲下去，手指抠住轮胎侧壁那道口子。` |
| **时间跳跃**（"三天后"） | 保留时间词，补一个**可看见的时间痕迹** | `三天后。车身擦得发干，轮毂上还挂着一线水；地上的油污清走了，水泥地上还留着几道没干透的印子。` |

---

## 七、绝不能做的事

1. 不新增原文没有的**人物、道具、情节、对话**。
2. 不改动**对白行**和 **`os` 行**一个字。
3. 不把 △ 行改成对白，不把对白并进 △ 行。
4. 不删除原文的**时间、地点、因果、结果**信息。
5. 不写"仿佛/似乎/好像"式模糊修辞（AI 渲染不出来）。
6. 不为了文采牺牲**可拍摄性**——这是本工作流的第一优先级。
