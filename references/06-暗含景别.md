# 暗含景别：不写景别名，却让镜头只有一个位置

> 本文件解决一个矛盾：剧本 △ 行**不许写**「特写／近景／镜头推近」（那是分镜层的活，写进剧本就越界了），
> 但交付稿又必须**有画面感**——读者要能立刻在脑子里定住一个机位。
>
> 解法不是加景别名，而是**改可见范围**。景别由「画面里装得下什么」决定，不由标签决定。

---

## 一、核心判断

一条 △ 行，读完能不能反问一句「那这一格镜头搁在哪」？

- 能答上来（景别唯一）→ 合格
- 答不上来，或者说「怎么拍都行」→ 不合格，要重写

```
❌ △ 老陈站在铺子门口，看着小王走远，心里有些不安。
     ↑ 一句话里三个景别都成立：门口全景、两人中景、脸近景。机位悬空。

✅ △ 门框里只装得下他半个人，肩抵着门框，手还搭在卷帘门的把手上没放。
     ↑ 读完只有一个位置：中景，过门框。没写「中景」一个字。

✅ △ 只看得见他捏着那截胶条的那两根手指，指甲缝里嵌着黑泥。
     ↑ 读完只有一个位置：特写。靠「只看得见」+「两根手指」限定出来的。
```

**不是把景别藏起来，是把它做成事实。**

---

## 二、五档可见尺度（写作时对准的靶子）

写之前先定这一条要哪一档，然后只给这一档装得下的东西。

| 档 | 画面里装什么 | 不该出现什么 | 靠什么限定（可用词） |
|---|---|---|---|
| **T0 大远景** | 人只剩一个影，空间是主角 | 任何面部、任何表情 | 整条街、半个镇、远处的、天边、满地、一直排到 |
| **T1 全景** | 整个人 + 一件空间标志物（门框／卷帘门／举升机／窗台） | 面部细节、指节 | 整个人、背影、站在…里、铺子、街、屋顶 |
| **T2 中景** | 半身，两个人的相对位置（隔多远、谁高谁低） | 单看某个局部就够的信息 | 隔着一张桌、一前一后、半步、并肩、侧过身 |
| **T3 近景** | 头肩，背景退成一片 | 第三个人、整屋布局 | 脸上、眼里、下巴、偏过头、只露出个头 |
| **T4 特写** | 一个局部，框里**没有第二样东西** | 空间、身体其它部位 | 只看得见、两根手指、指甲缝、胶条上的裂口、针脚 |

> 一条 △ 行**只服务一档**。要换档就另起一条（拆现有内容，不新增情节）。

## 三、六种暗含手法（不出现景别名）

### 1. 范围限定：用「只／只有／装得下」把框裁出来
```
只看得见他捏着那截胶条的那两根手指。       → T4
画里只剩半个肩膀和他手里的搪瓷缸。         → T4/T3
门框里装得下他半个人。                     → T2
```
「只」是最省力的景别开关——它直接把画面外的东西排除掉了。

### 2. 距离刻度：给两个人一个可量的间距
```
两人隔着举升机的机身，一个在车头一个在车尾。  → T2（关系镜头）
小王站在老陈背后半步，抬手才够到他的肩。      → T2/T3
```
距离一说清，机位就被逼到中间，退无可退。

### 3. 尺度对撞：给人和空间一个比例
```
整条街空着，只他一个人蹲在卷帘门底下。          → T0
铺子里堆着七八条旧胎，他蹲在最里头，小得像个墩子。 → T0
```
人和环境比例悬殊，观众自动读成远景。

### 4. 遮挡：让前景挡住人，景别自然变
```
被卷帘门挡住半个身子，只露出攥着钥匙的那只手。   → T2 + T4（一层遮挡切出两级）
隔着一排吊着的链条看他，人被切成几段。           → T2
```
遮挡是**唯一能在一格里安全装两级**的手段，因为它有物理依据。

### 5. 背景虚化：用「糊／辨不出／只剩」把背景推掉
```
身后整面墙糊成一片灰，只有他脸上有一点光。       → T3
背景里那些脸都辨不出，只有他一个在动。           → T3/T2
```

### 6. 出入框：用「伸进来／跨出去」交代框边
```
一只手从车底伸出来，抓住扳手。                   → T4（框外伸入）
他的后脚跟着跨出门槛，人就出去了。               → T1（出框）
```
注意：写「画面外／画框／入画」是元叙事，写**具体物件的进出**才是画面。

## 四、跨行节奏：一场戏的景别要有起伏

单条合格不等于一场好看。一场十几条 △ 行全是 T2，观众会觉得「闷」，说不清哪里不对。

**默认节奏（可直接套）**

```
场首 T1（定场）→ 中段在 T2/T3 之间收放 → 情绪落点 T4 → 场尾 T1/T0（人退出空间）
```

| 规则 | 判定 | 修法 |
|---|---|---|
| 场首优先 **T1/T0** | 每场第一条 △ 行给「空间 + 人 + 一件标志物」 | 补一句定场，不超过 45 字，不铺陈 |
| 允许用 T3/T4 开场（钩子） | 但**同一条里必须有空间坐标**（「铺子里，一床旧棉被搭在举升机上。老陈睁着眼……」），否则观众不知道这是哪儿 | 没有坐标就退回 T1 |
| 连续同档 | 不算错，镜头可以不切 | 只有在**连停 5 条以上**、或整场只有一个档时才要动 |
| 情绪最高点用 **T4** | 特写落在动作上，不落在形容词上 | 把「他很急」换成「牙关咬出腮帮的棱」 |
| 场尾用 **T1/T0** | 人从空间里退出去 | 别在特写上收场，除非要留钩子 |
| 一场内 T0 不超过 2 条 | 大远景多了会空 | 收掉一条，改成 T1 |

> **补定场的红线**：定场行里的空间信息**只能来自场次标题**（`第七场：修车铺・夜・内` → 可以写修车铺、夜、屋里），
> **不许新造地点、天气、季节**。标题没写的屋子长什么样，也不许编——只写标题已声明的那点空间 + 一个人 + 一件已在原文出现的物件。
> 这条不破，补定场就不是加戏。

**反例（一场 6 条全是中景，读起来像同一格重复）**
```
△ 老陈隔着台面坐下，把报单往桌上一放。
△ 小王坐在对面，两只手放在膝上。
△ 老陈侧过身，把报单往他那边推了推。
△ 小王低头看了看报单，又抬眼看她。
```
**改法：给场首一个全景定场，中段插一个特写，尾巴放到门口。**
```
△ 铺子里就一张台面两条凳，台面上吊着一盏灯，灯泡上落满灰。      ← T1 定场
△ 老陈隔着台面坐下，把报单往桌上一放。
△ 只看得见报单末尾那行小字，笔迹压得很重，纸被划破一道。        ← T4
△ 老陈侧过身，把报单往他那边推了推。
△ 小王把报单拎起来，走到门口又停住，人让门框切成一半。          ← T1 收
```

## 五、绝对不许写的东西

| 不许 | 为什么 | 改成 |
|---|---|---|
| 特写、近景、中景、全景、远景、大远景、景别 | 分镜层的词，进剧本就越界 | 用范围限定写出同样的框 |
| 镜头、机位、镜头推／拉／摇／移／跟／甩、俯拍、仰拍 | 元叙事 | 写物件位移、写遮挡变化 |
| 画外、入画、出画、构图、前景后景（作为术语） | 元叙事 | 「从车底伸出来」「让卷帘门挡住」 |
| 一个画面给不了的两级 | 模型只执行一个，另一个被丢掉 | 拆成两条，或用遮挡过渡 |
| 形容词代替尺度（巨大的、渺小的、空旷的） | 渲染不出来 | 给比例（七八条旧胎／他小得像个墩子） |

> 机检 `scripts/lint_shot_scale.py` 的 S1 会对上表第一、二、三行做硬拦截。

## 六、给下游留接口：剧本干净，景别可反推

剧本里不写景别名，但每一格的框是被**写死的**——所以可以反向推定。
`lint_shot_scale.py --shotlist` 会输出每场的推定景别序列，直接当分镜草表用：

```
第七场：T1 → T2 → T4 → T2 → T1
第八场：T1 → T2 → T3 → T4 → T1
```

用法分两条线，互不污染：

| 用途 | 拿什么 | 说明 |
|---|---|---|
| 给导演／演员 | 剧本原稿 | 一个字景别名都没有，演员按动作演 |
| 给分镜／AI 视频 | `--shotlist` 输出 | 反推的景别序列，作提示词的 framing 字段 |

如果 AI 视频模型必须要显式景别，就在**提示词阶段**补 `shot: close-up`，不要回头改剧本。

> 取档口径：一条 △ 行按**最紧**的那个元素取档（写了嘴唇就按近景算，不按屋子算），
> 因为要看见嘴唇，机位就必须近。一行里真写了两级（先全景交代、再落到指节）的，
> 草表取紧的那级，实际拍摄可分两格。

---

## 七、自查三问（每条 △ 行落笔前）

1. **这一条是哪一档？** —— 说不出来就还没想好，别落笔。
2. **框外的第二样东西进来了吗？** —— T4 里出现「整间屋」就是跨档，删。
3. **换一个景别还能不能成立？** —— 如果换成全景也一样通顺，说明你没写死，补范围限定。
