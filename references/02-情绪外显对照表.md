# 情绪 → 可见行为 对照表（剧本 △ 行专用）

> 依据 `vendor/show-emotion.md`（tance-mang/chinese-webnovel-skills）改编，
> 针对**剧本舞台指示**做了收窄：只保留镜头拍得到的行为，删掉纯内心体验。

**唯一原则**：△ 行里出现"他很愤怒/她很心疼/心里一紧"这类词，一律换成下表右侧的可见行为。
不告诉读者/模型"这是什么情绪"，让它**看见身体怎么了**，自己得出那个情绪。

---

## 一、六条通道（挑 1–2 条用，别全堆）

| # | 通道 | 取什么 |
|---|---|---|
| 1 | 神态 / 微表情 | 眼神、嘴角、眉头、视线落点 |
| 2 | 小动作 | 手、姿势、下意识动作 |
| 3 | 生理反应 | 呼吸、喉咙、指尖、肩背（**仅肉眼可见的**） |
| 4 | 动作承接 | 用下一个动作代替情绪说明（"没接话，蹲下去"） |
| 5 | 物件 / 环境烘托 | 一个具体物件或痕迹，克制 |
| 6 | 留白 | 动作完就停，不解释 |

> ⚠️ "对话潜台词"属于**对白行**，本工作流不改对白，故不在此列。

## 二、常见情绪 → 台词化可见行为（直接取用）

| 情绪 | ❌ 别写 | ✅ 这样演（可拍） |
|---|---|---|
| 心疼 | 我很心疼 | 伸手想碰，指尖快碰到时顿住，收回来把外套往他身上拢了拢 |
| 难过 / 痛苦 | 她很痛苦 | 扯了扯嘴角，挤出一个笑；低头咬住唇，眼眶热了一下，没抬手擦 |
| 愤怒 | 他很愤怒 | 后槽牙咬紧，指节攥得发白；把杯子轻轻放下——太轻了；声音反而压低 |
| 委屈 | 我很委屈 | 仰头把眼泪逼回去；"我没事"说得太快；低头扒饭，咽得很慢 |
| 失望 / 心寒 | 她失望透顶 | 平静得反常；侧开身；把东西从门缝推回去；"我累了" |
| 喜悦 | 开心极了 | 嘴角压都压不住；走路带风；反复看手里那张纸；声音不自觉扬起来 |
| 紧张 / 害怕 | 他很紧张 | 手心在裤子上蹭了一下；反复咽口水；脚往后挪了半步 |
| 震惊 | 他震惊了 | 僵在原地；倒吸一口凉气；手里的东西啪地掉在地上 |
| 尴尬 | 气氛很尴尬 | 没人说话；茶杯碰桌面的声音格外响；他低头摆弄手里的小物件 |
| 思念 | 我很想你 | 给那个再也不会回的号码发了条消息，又一个字一个字删掉 |
| 警觉 / 怀疑 | 他起了疑心 | 目光从人脸移到对方手里的东西上，停了两秒，没接话 |
| 认可 / 服气 | 心里暗暗佩服 | 原本要反驳的话咽回去，点了下头，蹲下去跟着一起干 |

## 三、剧本里最高频的三种「隐含情绪」改法

### 1. "没接话 / 没说话"
不要解释为什么沉默，直接给**沉默时身体在做什么**：
```
❌ △ 老陈没接话。（沉默=没有画面）
✅ △ 老陈没接话，把扳手往地上一放，蹲下去，手指抠住轮胎侧壁那道口子，往里按了按。
```

### 2. "看了一会儿 / 看了他一眼"
把"看"拆成**视线路径 + 落点 + 停顿**：
```
❌ △ 老陈站在车边看了一会儿。
✅ △ 老陈抱着胳膊站在车边没动，目光从车头慢慢移到挡风玻璃，又落到墙根那道水痕上，停了几秒。
```

### 3. "愣住 / 顿了一下"
给一个**可见的中断动作**：
```
❌ △ 小王愣了一下。
✅ △ 小王手里的车钥匙悬在半空，钥匙扣晃了两下才停，他才接上话。
```

## 四、克制铁律

- **1–2 个准细节就够**。堆五个动作 = 油腻 + AI 味。
- **成年人的情绪是收着的**，越克制越戳。别写嚎啕、剧烈颤抖。
- **环境烘托要具体、要轻**："那杯茶早凉了，她也没动" > "心如刀绞般凄凉"。
- **快节奏场次（打斗/打脸）可直给**，不必处处含蓄，看场景。
- 改完自查：这句话里有几个词是摄影机拍不到的？有就删。
