# 校验规则（改写后必跑）

> 对应 `scripts/check_rewrite.py` 的机检项 + 模型人工复核项。
> 任一 🔴 不过 → 该条打回重写，不得进入落盘阶段。

---

## 🔴 机检四项（脚本自动）

| # | 检查 | 判定 | 失败原因 |
|---|---|---|---|
| 1 | **对白零改动** | rewrite_map 的 key 全部是 `action` 类型段落 | 误改了对白 / os / 场次标题 |
| 2 | **△ 前缀保留** | 每条改写文本仍以 `△` 开头 | 丢了舞台指示标记，落盘后格式错乱 |
| 3 | **无不可演词** | 不出现禁词表里的纯心理/抽象词 | 写出了镜头拍不到的东西 |
| 4 | **可拍摄性** | 至少含 1 个身体动作词或物理细节词 | 改写后仍是抽象句，AI 无从下手 |

### 禁词表（机检项 3）
```
感到 觉得 心想 意识到 心里一紧 松了口气 暗自 暗暗 不禁 下意识地
气氛凝固 意味深长 说不出的 复杂情绪 心如刀绞 仿佛 似乎 好像
镜头拉近 特写 配乐 转场 画面定格
近景 中景 全景 远景 景别 机位 画外 构图 俯拍 仰拍 跟拍      ← 景别名属分镜层，一并拦截
```
> "下意识地"本身可拍（动作），但常带出不可拍的心理，故一并拦截，改用具体动作。

### 可拍摄动作词表（机检项 4，命中任一即通过）
```
站 蹲 坐 走 停 抬 放 伸 收 攥 抠 扒 摁 扒开 掀 拎 提 推 拉
看 盯 望 扫 瞥 别开 移 转 侧 低下 仰 点 摇 顿 顿住 僵
哼 咽 喘 咬 抿 扯 抖 颤 蹭 挪 蹬 撑 拱 舔 溅 滴 洒
砸 掉 滚 翻 渗 冒 擦 按 扣 捏 拢 扶 抵
```

## 🔴 全本机检（景别与节奏，`lint_shot_scale.py`）

逐条校验管不了「一场戏整体像不像一场戏」。改写全部落盘**之前**跑一次全本体检：

```bash
python3 scripts/lint_shot_scale.py parsed.json -o 镜头体检.md
python3 scripts/lint_shot_scale.py parsed.json --shotlist 分镜草表.md   # 可选
```

| # | 检查 | 级别 | 判定 | 为什么 |
|---|---|---|---|---|
| S1 | **元叙事景别词** | 🔴 FAIL | 出现 `特写 近景 中景 全景 远景 景别 镜头 机位 画外 构图 俯仰 跟拍 摇镜 淡出` | 越界到分镜层。景别要靠可见范围暗含，见 `06-暗含景别.md` |
| S2 | **一行跨两档** | 🟡 | 同一条里既有 T4 极近细节（指节/睫毛/针脚）又有 T0 大尺度（整条街/半个镇/小得） | 一个画面装不下，模型只会执行其中一个 |
| S3 | **同款收束** | 🟡 | 单场出现 `停住／没动／没再／顿住` 超过 2 次 | 一个模子写的，观众会觉得闷 |
| S4 | **缺定场** | 🟡 | 场首第一条 △ 行既无空间参照、又不是 T0/T1 | 没人交代「这是什么地方」 |
| S5 | **单档场** | 🟡 | 整场只有一档（≥4 条时判定），或一个机位连停 ≥5 条 | 全场没有景别变化 |

> 已知误报：`缝纫机的机位` 是实物位置不是摄影机位，脚本按上下文放行；但建议剧本里改写成「缝纫机前」更干净。

### 统计口径（不判错，看基线）

| 指标 | 读法 |
|---|---|
| **档位未判定** | 词表没命中的比例。**不是稿子缺陷**（「她把书合上，手指夹在那页里」明显是近景，但词表抓不到），只用于同一稿改动前后对比，不作跨稿验收线 |
| **同款收束率** | 模板尾巴占比，健康线 ≤5% |
| **缺定场场次** | 场首无空间交代，目标 0 |
| **换档次数/场** | 一场切几刀，小场 1–3，大场 3–8 |

### 分镜草表（`--shotlist`）

剧本里**不出现**任何景别名，但框是被写死的，所以可以反推。草表按「同档视为镜头不切」给出每场景别序列，
直接作 AI 视频提示词的 framing 字段用——**不要为了让模型看懂而回头往剧本里加景别名**。

```
第七场（5 条，换档 3 次）：T1 → T2 → T4 → T2 → T1
```

## 🟡 人工复核四项（模型自查，写进对照表）

| # | 检查 | 方法 |
|---|---|---|
| 5 | **事实不丢** | 把原文的时间/人物/物件/动作结果逐个数一遍，改写后是否都还在？ |
| 6 | **没加戏** | 有没有冒出原文没有的人物、道具、情节、天气、心理？ |
| 7 | **克制** | 是不是 1–2 个细节？有没有五个动作连发 / 排比 / 形容词堆砌？ |
| 8 | **长度** | 30–70 字为宜，超过 90 字要删 |

## 常见翻车案例

| 翻车 | 问题 | 修正 |
|---|---|---|
| `△ 老陈心里一紧，意识到轮胎有问题，神情复杂。` | 全是不可演词，且复制了对白信息 | 删掉，改成动作：`△ 老陈蹲下去，手指抠住轮胎侧壁那道口子，往里按了按。` |
| `△ 三天后的清晨，阳光温柔地洒进铺子，仿佛给一切都镀上了金边，小王心中充满希望地走向那辆车。` | 加了原文没有的天气/修辞/心理，且堆比喻 | 保留"三天后"，只补可见完成态：`△ 三天后。车身擦得发干，轮毂上还挂着一线水；地上的油污清走了，水泥地上还留着几道没干透的印子。` |
| `△ 老陈修车修得很快，很顺手，看起来非常满意。` | "满意"是评价不是画面 | 换成可见：`……扳手转了两圈就松了，他把螺丝一颗颗码在纸板上，摆得整整齐齐。` |
| `△ 老陈没接话`（照抄原文） | 没改 | 无画面 → 必须按 `02` 的"没接话"改法补动作 |
| 把 `小王：我明天来取。` 并进 △ 行 | 改了对白 | 🔴 直接违反硬约束 1，回退 |
